# worauf — Prior Art & UX Research

**Date:** 2026-09-02
**Scope:** existing tools for German *Rektion* (Verben/Adjektive/Nomen mit Präpositionen), learner pain points, and UX patterns worth copying.
**Confidence key:** **High** = I opened the artifact (page, source file, API response) myself · **Medium** = read via search-engine summary or a partial fetch · **Low** = inference, or blocked source.

---

## TL;DR

1. **Nobody treats the *case* as the thing being taught.** Every reference list prints `warten auf + Akk` as a static string; every trainer drills the *preposition* and lets the case fall out of the example sentence. Not one tool found asks "which case?" as its own question. This is worauf's whole thesis and it is genuinely unoccupied. *(High)*
2. **Nobody shows the meaning contrast next to the case contrast.** The German-language references (mein-deutschbuch, longua, sprakuko) list `sich freuen auf` and `sich freuen über` as adjacent rows with **no gloss at all**; DWDS splits senses correctly but marks case only implicitly, via the article inside a bracketed pattern (`⟨jmd. besteht auf einer Sache⟩`). The Russian-language sites (deutschonline.ru) *do* gloss the contrast — they are worauf's real competition, not the German ones. *(High)*
3. **The category is served by static HTML tables and PDF worksheets, not by software.** GitHub has essentially nothing: three targeted searches returned 9, 7 and 1 repositories, **every single one at 0 stars**. The one dedicated App Store app has **7 ratings**. There is no modern, filterable, linkable web tool for Rektion. *(High)*
4. **tja.progapanda.org's real trick is an *asymmetric* two-column filter, and it is directly transferable.** Read from source: the left reel is **hard-filtered** (rebuilt to only valid options), the right reel shows **everything** with invalid rows dimmed by colour only — and dimmed rows **stay clickable**, falling back to the first combination that does exist. That asymmetry is the answer to a 93%-empty matrix. *(High)*
5. **The literature backs worauf's existing distractor design specifically.** Little, Bjork, Bjork & Angello (2012) found that multiple-choice items with *competitive* wrong alternatives produce retrieval gains on later free-recall tests, because the learner retrieves why each wrong option is wrong. "Same preposition, different case" is the textbook definition of a competitive alternative. *(High)*

## Per-tool notes

### tja.progapanda.org — the format reference (read from source)

This is the most important entry, so it gets the most detail. **Everything here is read from the shipped `app.js` / `style.css` / `data.js`, not inferred.**

**It is not a symmetric two-column browser.** It is a *slot machine* with two reels, `#prefix` and `#stem`, and the two columns are treated **asymmetrically**:

- **Left reel (prefix)** is **hard-filtered and rebuilt** on every selection. The source comment is explicit: *"Every row here is already a real verb sharing the current stem, so picking one is always valid — no fallback needed, unlike the stem column below."* Only prefixes that actually form a word with the current stem are present as rows.
- **Right reel (stem)** shows the **complete list, always**. Non-combining stems get class `off`, styled `#stem .item.off { color: var(--dim); }` — **dimmed by colour only, not opacity, not `pointer-events: none`**. They stay clickable, and clicking one degrades gracefully:
  > *"A lit stem keeps the prefix you had. A greyed one cannot, so it takes the first prefix that does build a word with it — which is what the grey says will happen."*

That pairing — one side rebuilt, one side dimmed-but-live with a stated fallback — is the interesting answer to a sparse matrix, and it is directly portable to worauf's 196-of-2,624 grid. *(High)*

**Other verified details:**

- **URL state is one parameter, not two:** `?verb=<id>`, where `id` is the verb's own name. Homographs are disambiguated by a suffix (`umgehen`, `umgehen-2`) so "an ordinary link still works". A second param `?mode=cards` restores flashcard mode. Note this is **different from worauf's `?w=&p=`** — tja names the *pair*, worauf names the two *axes*. *(High)*
- **Two modes in one UI:** browsing (columns scroll normally, `scrollIntoView`) and testing (`state.testing` — reels animate, three copies of the strip are rendered for wrap-around, wheel/drag/keyboard scrub). One `<article class="card">` below serves both.
- **Rection is already in the data**, as a compact `use` field: `etw+A`, `jdn/etw+A · in etw+A`, `etw+A · dass-Satz`. The data file is a hand-editable pipe-delimited flat text file — *"a text file and a split, not JSON with a schema, so it stays editable by hand."*
- **`da-` pronominal adverbs are a first-class map** in `data.js`: `{ an: "daran", auf: "darauf", mit: "damit", über: "darüber", … }`.
- **Teaching baked into presentation:** separable prefixes are bolded, inseparable stems are bolded, so the stress rule (`ANnehmen` vs `überSETZen`) is re-taught on every single card rather than stated once in a footnote.
- **Card contents:** gloss, badge row (separable/inseparable · auxiliary · valency), a `<dl>` of Präsens / Präteritum / Perfekt / Nebensatz, and an "in the wild" example.
- **It already ships Russian** (`hreflang` en/ru/fr), and the locale switcher preserves the current card via the URL.
- **Mobile (verified CSS):** at `≤860px` the page stacks into `auto / 1fr` rows — reels on top, card below — but **the two reels stay side by side**, capped at `calc(var(--ih) * var(--reel-rows))` = 5 rows × 44px. Short viewports shrink the *row count*, not the layout: `≤720px` height → 4 rows; `≤560px` height → 3 rows at 40px. `prefers-reduced-motion` short-circuits the reel animation to a direct transform.
- **Repos:** [progapandist/tja](https://github.com/progapandist/tja) (Go TUI, 7★) and [progapandist/tja-web](https://github.com/progapandist/tja-web) (JS, 0★, described as *"two reels that filter each other"*).

**Limitations of the format, for worauf's purposes:** the prefix×stem matrix is *dense and productive* (95 stems × a handful of prefixes each, and a learner can guess `mit-` + `nehmen`). Rektion is **arbitrary and sparse** — there is no productive rule to discover by spinning, and the "I'm feeling lucky" random-spin affordance would be teaching noise. Also, tja's reels answer *"does this combination exist?"*; worauf must additionally answer *"in which case, and meaning what?"* — a third dimension the two-reel format has no slot for. *(Opinion, flagged; see recommendations.)*

### mein-deutschbuch.de — the canonical German list

Five-column table (`Infinitiv | Position 1 | Verb 1 | Mittelfeld | Verb 2`) that doubles as a *Satzklammer* demo: `ab|hängen von + Dat` / *"Ob ich mitkomme,"* / *"hängt"* / *"vom Wetter"* / *"ab."* Case is explicit and consistent. Multi-preposition verbs get adjacent rows (`s. beklagen bei + Dat` and `s. beklagen über + Akk`; `s. freuen auf + Akk` and `s. freuen über + Akk`). **No translations, no glosses, no sort, no search, no filter** — a PDF that happens to be HTML. Exercises live on a separate page: 10 gap-fills, 10 question-formations (`Fragen Sie nach der Präpositional-Ergänzung` — i.e. *worauf?* drilling), 10 sentence-ordering. *(High)*

### DWDS — the best meaning-splitting, the worst case-marking

The dictionary entry for `bestehen` is the single best presentation of the "same verb, different preposition, different meaning" problem found anywhere:

- Sense 2: `⟨etw. besteht aus etw.⟩` "sich aus etw. zusammensetzen"; `⟨etw. besteht in etw.⟩` "etw. als Inhalt haben"
- Sense 3: `⟨jmd. besteht auf einer Sache⟩`, `⟨selten jmd. besteht auf eine Sache⟩` "an etw. festhalten"

Note what sense 3 does and does not do: it correctly records that `bestehen auf` is **normally Dativ, rarely Akkusativ** — a nuance no learner list carries — but it never writes the word "Dativ". The learner must decode the case from `einer Sache` vs `eine Sache`, which is precisely the skill they don't have yet. **That is the gap in one sentence.** *(High)*

The separate **Wortprofil** (`/wp/warten`) is corpus-statistical: relation labels `hat Präpositionalgruppe`, `hat Akkusativ-Objekt`, `hat Subjekt`, each with logDice and frequency (`vergeblich warten`, logDice 8.8, n=10,750). It surfaces `auf Antwort`, `auf Bus`, `mit Spannung` — real, frequency-ranked, **and case-blind**. Built for linguists. *(High)*

### verbformen.de / netzverb

The best-resourced site in the space (160k+ headwords, apps on both stores). Per-verb it prints valency as pattern sentences: `jemand/etwas wartet auf etwas`, `jemand wartet auf etwas irgendwo`. Search summaries also report a compact form `(Akk., auf+D, von+D, mit+D, auf+A)` on some surfaces, which *does* distinguish `auf+D` from `auf+A` — but the conjugation page I opened showed the pattern sentences **without** case labels, and never explains what the two `auf`s mean differently. **No reverse lookup**: there is no way to ask "show me every verb that takes `auf`". No trainer — worksheets, flashcard PDFs and word-search puzzles instead. *(High for the page I opened; Medium for the compact notation.)*

### The Russian-language competitors — worauf's actual rivals

**deutschonline.ru** is the closest thing that exists to worauf's content model: a table with an explicit case column (A/D), a Russian gloss per verb, a German example **and its Russian translation**, and — crucially — it *does* run the contrast, listing `denken an + A` and `denken über + A` as separate glossed rows. Verbatim rows: `arbeiten — работать | an | D | Sie arbeitet an einem neuen Projekt. — Она работает над новым проектом.` and `freuen (sich) – радоваться будущему | auf | A | Ich freue mich schon sehr auf die Ferien.` Two exercises at the end. It is static, unsearchable, unlinkable at row level, and buried in an SEO article — but the *content* is right. *(High)*

**crazylink.ru** is the closest existing *trainer*: 143 verbs, sessions of 10/15/20, and the exercise is **assemble-the-phrase-from-fragments** driven by a Russian prompt — *"Дан перевод словосочетания с глаголом, нужно собрать из предоставленных фрагментов перевод"* — with a `--` option when no preposition is needed. Feedback is immediate and binary (*"Верно!"* / *"Ошибочка…"*). No streak, no score counter, no SRS; registration is optional and only persists results. **This is the only tool found that drills the preposition and the case in the same act**, because assembling `auf die Ferien` requires choosing the article form. *(High)*

### Apps

The dedicated app is **German Verbs Past Prepositions** (Bita Sobhani), iOS + Android, 600+ verbs with English translations, explicitly marking *"either Akkusativ (A) or Dativ (D), or rarely Nominativ (N)"* — the right data model. Free with a $2.99 ad removal, v1.1.4 (13 Dec 2025), 3.4 MB. It has **4.7 stars from 7 ratings**. Seven. After seven years on the store. *(High)* — Read as market evidence, not as a quality judgement: dedicated Rektion tooling currently has no distribution.

Everything else on the stores is conjugation-first with prepositions as a footnote (Verben PRO: 14,000 verbs, offline, "includes fixed prepositions"; Netzverb's *Verbs German Dictionary*).

## Learner pain points — with evidence

Reddit was unreachable (see Methodology), so this section is built from **german.stackexchange.com**, queried through its API. View counts are the best available demand proxy.

### The corpus is dominated by preposition-and-case questions

Tag census on german.SE: `preposition` **963** questions, `grammatical-case` **777**, `dative` **409**, `accusative` **265**. Only `meaning`, `translation`, `word-usage`, `english-to-german` and `difference` are larger, and those are catch-alls. *(High)*

### 1. "Is there a system, or do I just memorise it?" — the load-bearing question

[Q 76278 — *"Rektion der Verben bei Präpositional-Ergänzungen: gibt's einen Weg zu bestimmen, ob man den Akkusativ oder Dativ benutzt?"*](https://german.stackexchange.com/questions/76278/) — the asker lays out `sich verlassen auf + Akk` against `sich beteiligen an + Dat` and asks:

> *"Gibt es irgendwelches System, mit dem man bestimmen kann, was die richtige Rektion bei jedem Fall ist? Oder hat man es nur aufwendig zu lernen? … bei vielen Präpositional-Ergänzungen kommt es mir schwierig vor, zu sehen, ob es überhaupt eine Logik gibt."*

The **accepted answer**: the system existed in Proto-Indo-European and has eroded since —
> *"Wenn es Dir also 'nur' darum geht, Deutsch (heutiges Deutsch) richtig zu sprechen, dann bist Du tatsächlich mit Auswendiglernen am besten bzw. schnellsten dran."*

Corroborated in the wild by easy-deutsch's own framing: *"there are rarely clear rules about when to use which preposition. That's why you have to memorise verbs with prepositions."* **The expert consensus is that this content must be memorised — which is the strongest possible argument for a drilling tool over another explanation page.** *(High)*

### 2. `auf` + Akk vs `auf` + Dat — worauf's flagship confusion, documented

[Q 76494 — *"Frage über eine Wechselpräposition: Warten AUF…?"*](https://german.stackexchange.com/questions/76494/) is worth shipping as content. The learner reads *"Die zwei Mädchen müssen auf der Ampel warten"*, panics, and writes: *"Ich hatte immer gedacht, es wäre warten auf + Akkusativ."* The two answers resolve it exactly along worauf's axis:

- **Akkusativ** = the *event* being waited for. *"die Wendung im Akkusativ [stellt] immer ein Ereignis dar, auf das man wartet."* → *Die zwei Mädchen müssen auf **die** (grüne) Ampel warten.*
- **Dativ** = the *place* where the waiting happens. *"Zwei Mädchen sind auf eine Ampel geklettert … Bis die Feuerwehr kommt, müssen sie auf **der** Ampel warten."*

Same verb, same preposition, one letter of difference, two unrelated situations. *(High)*

Reinforced by [Q 77317 — *"aufsetzen auf / aufbauen auf: mit Akkusativ oder Dativ?"*](https://german.stackexchange.com/questions/77317/): *"I cannot really figure out why, as I do not see here the usual concept of 'direction VS place' that normally guides the casus with Wechselpräpositionen"* — i.e. the learner has the Wechselpräposition rule and has correctly noticed **it does not apply to prepositional objects**. And by the raw cry of [Q 71460 — *"I can never understand what case to use ever"*](https://german.stackexchange.com/questions/71460/). *(High)*

## UX patterns to adopt / avoid

*From here on, recommendations are **my opinion**, built on the observations above. Observations remain marked.*

### Sparse two-column matrices

**Observed:** tja solves 95×N sparsity asymmetrically — hard-filter one column, colour-dim the other while keeping it clickable with a documented fallback. *(High)*
**Observed:** NN/g's filtering guidance says to prevent zero-result dead ends, show real-time counts, and grey out zero-result facets as non-clickable. ([nngroup.com/articles/applying-filters](https://www.nngroup.com/articles/applying-filters/)) *(Medium)*

**Adopt.** worauf's matrix is 196/2,624 ≈ **92.5% empty** — worse than tja's. I would take tja's asymmetry but **invert which side dims**, and depart from NN/g on one point:

- **Words column: hard-filter.** Selecting `auf` should rebuild the left column to the ~30 words that take `auf`. A list of 164 words with 134 greyed is visual noise.
- **Prepositions column: never filter, always dim.** 16 prepositions is small enough to hold as a stable spatial map. Keeping all 16 in fixed positions means the *shape of the dimming is itself the lesson* — "`bestehen` lights up three of sixteen" is information you cannot get from a filtered list.
- **Depart from NN/g: keep dimmed prepositions clickable.** NN/g's zero-result guidance is written for e-commerce, where a dead end is a lost sale. Here a dead end is *pedagogically valuable* — a learner clicking `warten` + `über` should be told **"`warten über` doesn't exist — you probably want `warten auf + Akk` or `sich beschweren über + Akk`"**, which is a teaching moment no reference table offers. Follow tja's precedent of graceful fallback rather than the greyed-out-and-inert convention.
- **Adopt counts, not just badges.** The brief mentions badging multi-preposition words. Show the *number* (`bestehen ³`), because "how many" is the discriminating information and it costs nothing.

**Avoid:** `opacity` for dimming (kills contrast ratios for the dimmed text at A2 reading level — tja uses a colour token, `color: var(--dim)`, which is the right call). **Avoid** `pointer-events: none` on dimmed rows. **Avoid** animating the reels for the browse mode — tja's slot-machine physics fit a productive matrix where spinning teaches; in an arbitrary matrix, randomness teaches nothing and costs orientation.

### Showing "same word, different preposition, different meaning"

**Observed:** DWDS does this best (numbered senses, each carrying its own `⟨…⟩` rection) but never names the case. Learner lists (mein-deutschbuch, longua) name the case but carry **no gloss at all**, so `s. freuen auf + Akk` and `s. freuen über + Akk` sit adjacent and look like free variants. deutschonline.ru is the only tool observed that does both — and only as static prose. *(High)*

**Adopt:** treat the **minimal pair as a first-class object**, not as two rows that happen to be adjacent. When a selected word has >1 preposition, the detail pane should render them **side by side in one comparison block**, each with: preposition + case, Russian gloss, and one German example whose article makes the case visible (`auf **die** Ferien` / `auf **der** Ampel`). Bold the article, the way tja bolds the stressed prefix — make the grammar visible in the example rather than stated beside it.

**Adopt** DWDS's honesty about frequency: `bestehen auf` is normally Dativ, *rarely* Akkusativ. A learner tool that flattens that to "Dativ" is teaching a small lie; one that presents both equally is teaching confusion. A "rare" tag costs one field.

**Avoid** the mein-deutschbuch failure mode: never print two prepositions for one word without glossing the difference. That is worse than omitting the second one.

### Trainer design

**Observed — the strongest single finding for worauf's existing design:**
> Little, J. L., Bjork, E. L., Bjork, R. A., & Angello, G. (2012). *Multiple-Choice Tests Exonerated, at Least of Some Charges: Fostering Test-Induced Learning and Avoiding Test-Induced Forgetting.* **Psychological Science, 23(11), 1337–1344.** DOI [10.1177/0956797612443370](https://doi.org/10.1177/0956797612443370) · [PDF](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/07/Little_EBjork_RBjork_Angello_2012.pdf)

The finding: multiple-choice practice with **competitive** incorrect alternatives improved later **cued-recall** performance on *related but untested* material — attributed to learners retrieving not only why the correct option is correct but **why each incorrect option is incorrect**. Non-competitive alternatives produced no such benefit. *(High)*

**worauf's stated distractor rule — "include the same preposition in a different case" — is a textbook competitive alternative, and it is the difference between a multiple-choice trainer that works and one that doesn't.** Keep it. Make it the documented rule, not an implementation detail.

**Observed:** the MC-vs-production literature is genuinely mixed. Short-answer imposes more retrieval effort and *may* produce more learning, but results conflict, and **feedback is the moderator** — short-answer benefits show up when feedback is given. *(Medium — [retrievalpractice.org](https://www.retrievalpractice.org/strategies/2018/multiple-choice), ERIC reviews)*

**Adopt:** MC as the default, typing as an opt-in hard mode — but only if typed answers get **immediate** per-item feedback. **Avoid** copying german.net's and schubert-verlag's batch "Check answers" model: 19 typed items scored at the end is the exact condition under which production practice loses its advantage.

**Adopt** crazylink.ru's insight, which is the best trainer idea observed anywhere in the space: **make one question require both the preposition and the case**, by having the learner assemble `auf ___ Ferien` (preposition + article). A single item that forces both retrievals beats two items that each force one.

**Observed:** Kim, S. K., & Webb, S. (2022). *The Effects of Spaced Practice on Second Language Learning: A Meta-Analysis.* **Language Learning.** 98 effect sizes / 48 experiments / 3,411 participants; **medium-to-large effect for spacing**; equal and expanding schedules statistically equivalent; longer gaps show small advantages only on *delayed* tests. Caveat stated by the authors: **the majority of included studies examined vocabulary, and more research on L2 grammar is needed.** ([Wiley](https://onlinelibrary.wiley.com/doi/abs/10.1111/lang.12479)) *(High)*

**Adopt** spacing, but **avoid** building an SRS. "Equal and expanding are statistically equivalent" means a simple missed-items queue that resurfaces failures after N intervening items captures most of the effect. A full FSRS/SM-2 scheduler brings account state, sync and a review-debt guilt loop — Anki already exists and already has decks for this. Compete on the *browser*, not on the scheduler.

**Avoid** streaks as a headline metric. No evidence either way was found in this research, and the tool's realistic session is "look up `bestehen`, drill twelve pairs, leave" — a daily-streak mechanic manufactures an obligation the content doesn't need.

### Mobile behaviour for two-column layouts

**Observed (from tja's CSS):** at `≤860px` the page becomes `auto / 1fr` rows — columns block on top, detail card below — and **the two columns remain side by side**, height-capped to a row count (`--reel-rows: 5` at 44px), which drops to 4 rows at `≤720px` viewport height and 3 rows at 40px at `≤560px`. `prefers-reduced-motion` bypasses animation entirely. *(High)*

**Adopt this wholesale.** It is the correct answer and it is already solved.

- **Never stack the two columns vertically on mobile.** The entire value of a dual list is seeing the relationship between the two sides at once; stacking destroys the product and leaves a worse list than the ones already on the web.
- **Cap by row count, not by `vh`.** Shrinking `--rows` on short screens keeps the detail card — the thing that actually teaches — above the fold. This also dodges the iOS Safari dynamic-viewport problem.
- **worauf has an advantage tja doesn't:** 16 prepositions fit in a fixed non-scrolling block on any phone. The prepositions column can be a static grid (4×4 or 2×8) while only the words column scrolls — better than two competing scroll regions on a touch screen.

### URL state

**Observed:** tja encodes the *pair* as one opaque id (`?verb=aufnehmen`), with a `-2` suffix disambiguating homographs, plus `?mode=cards`. Locale links preserve it. *(High)*

**Adopt** worauf's `?w=&p=` over tja's single id — with worauf's asymmetric data it must express three states (word only, preposition only, both), which one id cannot. But **steal two specifics**: (a) `?mode=` for the trainer, so a drill is linkable; (b) tja's homograph discipline — if worauf ever has two senses of the same word with different rection (`bestehen`), the URL needs to name the sense, and retrofitting that later breaks every shared link. Decide the id scheme now.

## Differentiation opportunity for worauf

*Opinion throughout.*

Three gaps are real, defensible, and none of them require out-building anyone on content volume.

**1. Case as a taught object, not a printed suffix.**
Every tool in the table renders the case as a string appended to the preposition. Not one asks the learner to produce it, and not one explains that `warten auf + Akk` and `warten auf + Dat` are different constructions rather than a rule and its exception. Meanwhile the SE evidence shows the *case* is what learners are actually stuck on (Q 76278, 76494, 77317, 71460) — they usually know the preposition. **worauf's multiple-choice distractor rule already targets exactly this, and Little & Bjork (2012) says that specific choice is what makes MC work.** This is the product.

**2. The minimal pair as the unit of content, glossed in Russian.**
The highest-traffic learner questions in this entire research are all minimal pairs (`freuen auf/über` at 83k views; `sprechen von/über` at 28k). The German-language references present these pairs *without glosses*; DWDS glosses them *without naming the case*; only Russian static articles do both, and they can't be linked to, filtered, or drilled. A shareable URL per pair — `?w=freuen&p=auf` next to `?w=freuen&p=über`, both glossed in Russian, both with a case-revealing example — is a better answer to those 83,000 searchers than anything currently ranking for them.

**3. Nouns and adjectives, at parity with verbs.**
`die Angst vor + Dat` and `stolz auf + Akk` are in worauf's brief. In the field: longua splits adjectives onto a separate page; Lingolia and one Memrise course cover all three; **everyone else is verbs-only**. Yet the noun-rection question `eine Frage nach / zu / über` has **81,381 views** — as much demand as the top verb question. A single browser where the part-of-speech is a filter rather than a different website is a straightforward structural win, and worauf's prototype already has that filter.

**On the two-column browser specifically:** I would frame it as the *reference* half of the product and the trainer as the *practice* half, with the browser feeding the trainer ("drill these 3 pairs" from the `bestehen` detail pane). The browser is the differentiated, linkable, SEO-visible surface; the trainer is where the learning happens. Building either alone reproduces something that already exists.

**What not to compete on:** content volume (verbformen has 160k headwords), exercise count (deutschakademie has 25,000; grammatiktraining has a better exercise set than worauf will), or scheduling (Anki wins). Compete on the case, the contrast, and the link.

## Open questions

1. **Reddit is unresearched.** Every `reddit.com` path was blocked. The "what learners wish existed" half of the brief is genuinely unanswered — german.SE tells you what confuses people, not what they'd install. Worth redoing from a network that can reach it, or via a Pushshift-style mirror.
2. **Is preposition → word lookup a real need?** It is half the two-column UI and it has the thinnest evidence in this report — zero SE questions ask it, and only sprakuko organises by preposition. It may be a *browsing* affordance (valuable for discovery and SEO) rather than a *task*. Worth a cheap test: does anyone ever land on `?p=auf` with no `w`?
3. **Anki deck sizes are unknown.** AnkiWeb's SPA blocked metadata. Download counts on "German Prepositional Verbs (+Cases)" would be the single best available number for whether SRS demand exists here — worth getting from a browser.
4. **Do Memrise community courses still exist?** The four course URLs resolve in search results, but Memrise's status on user-generated content is unverified here. Don't cite them as live competitors without checking.
5. **Audio: no evidence found in either direction.** Nothing in the SE corpus or the tool survey suggests learners want to hear `sich freuen auf die Ferien`. Before building TTS, find one learner who asked.
6. **The 196 pairs need a provenance decision.** mein-deutschbuch (~100 verbs), longua, sprakuko (25 + Gesamtübersicht), deutschonline.ru and the DaF textbook lists all disagree at the margins, and DWDS's `⟨selten … auf eine Sache⟩` shows why: rection is frequency-graded, not binary. Which source is authoritative, and does the data model carry a "rare / disputed" flag? tja's answer — a hand-editable pipe-delimited flat file, deliberately not JSON-with-a-schema — is worth copying for a dataset this size.
7. **Does the trainer teach Pronominaladverbien?** `worauf` is literally the product's name, and `worauf wartest du?` / `darauf` is where the preposition and the case become *invisible* (the case is baked into the fused form). tja ships a `DA` map; grammatiktraining devotes three exercises to it. Currently out of scope in the brief — deliberate, or an oversight?
8. **Verify the Lingolia entry.** Two fetches returned navigation chrome only. It is the most commercially serious freemium player in the table and is currently assessed at Low confidence.
